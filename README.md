# Verita

**Detect → Decide → Defend.** An anti-money-laundering system that finds laundering *patterns* in a
transaction graph, tells a compliance team exactly how much risk it accepts at its staffing level,
and produces case files whose every sentence is machine-verified and cryptographically signed.

> Status: under construction. Progress is tracked in [TRACKER.md](TRACKER.md); the full plan is
> [PIVOT.md](PIVOT.md).

## Quickstart

Requirements: Python 3.11, [uv](https://docs.astral.sh/uv/), Node 20.

```bash
cd backend
uv sync --extra dev
uv run poe migrate
uv run verita users seed-demo
uv run poe serve
```

```bash
cd frontend
npm ci
npm run dev
```
